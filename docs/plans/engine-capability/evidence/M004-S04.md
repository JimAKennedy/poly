**The editor is cycled by the host.** `remote.py editor close|open` sends CC 24
to the instrument slot's edit switch, so Poly sees Cubase's own close path
rather than a killed window. Three cycles, then a bridge round trip -- a
`ready` request and the `state` push it brings back -- and four bars compared

**A runner fact the spec depends on.** Closing the editor removes the CDP
endpoint entirely -- WebView2's browser process goes with the window -- and
reopening brings up a new endpoint with a new page. A handle never survives a
cycle, so the spec reconnects; `s04-skip-reattach` keeps the stale one.
