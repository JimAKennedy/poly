## M004/S02 — task 1: the preset sweep, its contract, and the workflow step

- `format` → exit 0
- `cubase-harness` → exit 0: typecheck clean, 23 Playwright unit cases, 35 Python cases

`lib/preset-contract.ts` reads `site/src/generated/presets.json` into one
expectation per preset and compares it against what the host showed. It throws
rather than returning a partial list when the file's shape is wrong — a contract
built from a file that silently changed is worse than none, because the sweep
would then compare against nothing and report success.

Nine unit cases prove the comparison decides both ways without a DAW: a wrong
lane count, wrong note numbers, a preset never observed, every mismatch reported
rather than the first, and the mutation knob turning a correct observation into
a failure.

`preset-recall.spec.ts` selects each of the 45 presets through the shipping
menu — `#presetMenu [role="option"][data-index]` — and reads the lane count and
note numbers back from the `.strip .stat` line the WebUI renders. It clicks the
`All` category chip first: the menu filters by category, and a filtered menu
would silently skip indices rather than fail.

Two distinct assertions, deliberately:

- **the host survives each selection**, with the index named if it does not.
  That is the `kWebPresetLaneNames` crash, and the index is the only useful
  thing to know about it.
- **each preset loads correctly**, compared against `presets.json`. A preset
  that loads wrongly passes a survival-only sweep, which is the difference
  between "did not crash" and "works".

The read-back uses the shipping DOM rather than a debug state dump, because
there is no such dump in the embedded host and adding one would put test-only
code in the product.

**Not yet proven against Cubase.** `cubase-harness` does not run a DAW. This
slice's row stays `open` until a nightly names it, per the milestone's own rule.

## M004/S02 — task 2: proved in a real Cubase, both ways

- `format` → exit 0
- `cubase-harness` → exit 0: typecheck clean, 27 Playwright unit cases, 35 Python cases
- `ledger` → exit 0, conforms with the slice `done`

**Green:** [run 35046414001](https://github.com/JimAKennedy/poly/actions/runs/35046414001)

> `ok 1 preset-recall.spec.ts:99:3 › L4-web: every factory preset loads inside
> Cubase › select all 45 presets and compare each against presets.json (18.3s)`

All 45 factory presets selected in a live Cubase over CDP, the host surviving
every selection, and every preset's lane count and note numbers matching
`site/src/generated/presets.json`. 31 of those 45 had never been opened in a DAW
before this run.

**Red:** [run 35048220827](https://github.com/JimAKennedy/poly/actions/runs/35048220827),
dispatched with `e2e_mutate=s02-malformed-preset`

> `preset 7 (Kotekan Interlock): 4 lanes in the host, 5 in presets.json`

The shape of that run is the proof, not just its failure. **Only the preset
sweep went red** — the toggle e2e and the export e2e both passed in the same
run — so the knob turns the intended spec red and nothing else. And the message
names a real observation: the host genuinely reported 4 lanes, and the mutated
contract claimed 5.

**An ordering failure found on the first dispatch, and the rule it establishes.**
[Run 35045855242](https://github.com/JimAKennedy/poly/actions/runs/35045855242)
had this sweep passing while turning the *export* spec red — `track 1 name
'Clap' is not in the expected lane names`. The sweep leaves the plugin on the
last preset rather than the fixture's patch. There is exactly one correct
position for it: after `Play scenario`, whose output is compared to a golden,
and before `Quit Cubase`, since it attaches to a live editor. Both constraints
are now in the workflow comment, and the same rule binds S01, S05 and S06.

**A promise the knob could not keep.** `M004-decisions.md` said one red dispatch
exercises every red path at once; `POLY_E2E_MUTATE` was compared for equality
against a single name, so it could only ever turn one spec red. It is now a
list, read through a shared `mutationActive()`. Caught before three more specs
were written against the broken convention.
