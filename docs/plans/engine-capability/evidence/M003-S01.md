`GrooveStateCopyBenchmark.ReportsFactSizes` failed: `GrooveState` grows
13776 → 15888 bytes, +2112, the largest single growth the struct has taken. The
guard exists to force a conscious decision, so it was answered with a
measurement rather than a new constant — the three-copy pipeline runs at
**0.45 µs/block, 0.02% of a 128-sample block period**, and
`ThreeCopyPipelineFitsBlockBudget` passes.

The first test run failed at a `1e-9` tolerance because `1.1f / 0.9f` differs
from the double ratio by about 6e-8. The engine was right and the test was
wrong: the profile is stored as `float` by design, so a tolerance tighter than
float precision tests the storage type rather than the arithmetic.
