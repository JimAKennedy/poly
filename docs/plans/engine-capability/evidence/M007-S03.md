## M007/S03 — task 2: the coverage rule locked, proved, and the slice closed

Written test-first. With no markers anywhere, the new case failed naming **all
fourteen** tokens — not a parse error, a list — which is the evidence it reads
both `.jk/validations.yml` and `scripts/pre-push-check.sh` correctly. Adding
seven `# pre-push-token:` markers and seven `# pre-push-exempt:` reasons took it
to zero.

Four arms, each proved with a throwaway `probe-token`:

| Probe state | Result |
|---|---|
| token accounted for by nothing | `probe-token is neither run by the pre-push gate nor declared exempt` |
| `# pre-push-exempt:` with nothing after the dash | `carries a pre-push-exempt marker with no reason after the dash` |
| both run *and* exempt | `is both run by the pre-push gate and declared exempt from it` |
| `# pre-push-token:` naming a token that does not exist | `declares '# pre-push-token: no-such-token', which is not a declared token` |

The third and fourth arms are not decoration. Contradictory markers would let a
token look accounted for from either file alone, and a marker naming nothing
would rot silently the first time a token was renamed.

**`format` is deliberately exempt rather than marked run.** Step 1 runs
`pre-commit run clang-format` on staged files; the token is
`pre-commit run --all-files`. Marking it would have made the check certify
something untrue, and the narrower arm is the more useful push-time gate.

**The check runs in CI, verified rather than assumed.**
`doc-conformance-wiring.test.mjs` is in `check-doc-conformance.sh`'s `TESTS`
array and the new case appears in that runner's output.

**An execution error worth recording.** The arm-3 proof restored its probe with
`git checkout -- .jk/validations.yml scripts/pre-push-check.sh`, which also
discarded the fourteen markers added minutes earlier and never committed. The
next validation run failed — correctly, and for the real reason — and the markers
were re-applied. The check caught the damage the proof did to it, which is
mildly reassuring, but the lesson is the cheaper one: commit before running a
proof that restores files by checkout.
