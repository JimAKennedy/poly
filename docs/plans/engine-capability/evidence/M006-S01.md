# M006/S01 — evidence

## M006/S01 — task 1: the wrapper, and the token repointed

- `format` → exit 0
- `doc-discipline` → exit 0 via `bash scripts/check-doc-discipline.sh`, output
  carrying exactly one `doc-drift` line (`no mapped sources touched`)

The script resolves a base from `GITHUB_BASE_REF` first — CI sets it, and
second-guessing a value CI already decided on would be the wrong kind of clever
— then `origin/HEAD`, then `origin/main`. With a base it runs
`jk-standards all --base`, and then greps its own captured output for a
`doc-drift` line, failing if there is none.

That last step is the whole point rather than belt-and-braces. Measured on this
tree before the script was written: `jk-standards all --base
origin/nonexistent-ref` printed **no** `doc-drift` line at all and exited 0. So
a token reading `jk-standards all --base origin/main` would have reported
success while the check never ran, on any clone where that ref is not fetched.
Asserting the check *ran* is the only arm that cannot reproduce the bug it
exists to remove.

With no base determinable the script explains — naming all three things it
looked for and how to fix it — and runs the remaining checks rather than
failing, so a detached HEAD or shallow clone stays usable. Explaining is not
skipping in silence; the behaviour being replaced was a skip line that reads
like a pass in a wall of green.
