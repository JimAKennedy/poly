### The correction

Task 1 claimed `jk-standards all --base <unresolvable>` prints nothing and exits
0, and argued from that a bare `--base` token would silently skip. **It exits 2**
with `cannot resolve base ref`. The wrong reading came from running the command
through a pipe and reading `$?`, which was `tail`'s status rather than
jk-standards'. Measured directly:

| Case | Exit | `doc-drift` line |
|---|---|---|
| no base at all | 0 | `doc-drift: … — skipped` ← the real bug |
| unresolvable base | 2 | none — fails loudly |
| good base | 0 | `no mapped sources touched` |

So supplying the base is the entire fix, and the assertion had no silent-skip
path to guard. Worse, it could never have fired — with a base doc-drift always
reports, without one the script takes the other branch — and had it fired it
would have been **wrong**: it matched any line beginning `doc-drift`, and the
skip message begins `doc-drift`, so it would have passed on a skip. An
unreachable check that would be wrong if reached, inside the milestone about
checks that pass without running. Removed in its own commit that states the
mis-measurement plainly.

### A second mistake, caught by its own output

The first attempt at these proofs ran against the **old** script. Proof 1 ends
in `git reset --hard HEAD~1` to drop the scratch commit, and that discarded the
uncommitted rewrite along with it — so all three proofs exercised the code they
were meant to replace. It surfaced because proof 3 printed the old script's
wording. The correction was then committed *before* re-running, so the revert
had nothing of mine left to destroy.

### The three proofs, against the committed script

- **A real drift violation bites.** A scratch commit touching
  `engine/tools/emit_presets.cpp` without `docs/preset-taxonomy.md` — the
  mapping M005 hit — failed with exit 1 and `Doc drift: change touches
  engine/tools/emit_presets.cpp but not 'docs/preset-taxonomy.md'`.
- **An unresolvable base fails loudly**, exit 2, `cannot resolve base ref
  origin/nonexistent-ref`. Inherited from jk-standards and deliberately not
  guarded.
- **No base determinable explains and continues.** Staged by deleting
  `refs/remotes/origin/HEAD` and `refs/remotes/origin/main` after recording
  both, running with `GITHUB_BASE_REF` unset, then restoring them with
  `git update-ref` and `git symbolic-ref`. Exit 0, the explanation printed, and
  three other named checks still ran. Refs verified restored afterwards and the
  wrapper green again.
