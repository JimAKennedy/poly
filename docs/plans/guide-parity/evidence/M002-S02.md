## M002/S02 — task 1: a metric-position weight for ghosts

- `format` → exit 0
- `unit` → exit 0, 660 tests, 0 failures
- `engine-isolation` → exit 0, 537 tests, 0 failures
- `rt-safety` → exit 0

Ghost-add is weighted by distance to the next accent versus distance from the
last, so the approach to a backbeat is favoured and the step immediately after
one is quieter. A step midway between accents sits near neutral: the row asks
for a gradient toward accents, not a blanket lift on weak steps, and a case
pins that difference.

`ghostGrammar` is scaled by the Complexity macro in `macro.cpp`, using the same
`lerp` shape the envelope depth already uses, so low Complexity keeps grooves
clean — which the row states and a case checks.

**A wiring error the unit tests structurally could not see.** The first probe —
discarding the ghost weight where the sources compose — **killed nothing**. All
four cases exercised `computeGhostWeight` directly, so the weight could be
computed perfectly and thrown away with every test still green. That is this
milestone's standing warning arriving in practice.

Adding a render-level case caught a real defect immediately, and the numbers
said so: the approach share was **identical** at 0.5449 with and without the
grammar. The helper took an accent-pattern parameter and the engine was passing
the lane's *onsets*; on a fully-lit lane every step then read as accented and
the "an accented step is not a ghost candidate" guard returned neutral
everywhere.

The fix removes the parameter rather than correcting the argument:
`computeGhostWeight` now reads `cfg.accents` itself, so there is no longer a way
to pass the wrong thing. Re-probed: the render case fails, the four unit cases
correctly survive.

| Case | Under the probe |
|---|---|
| neutral when unset | passes — about the unweighted path |
| favours approach over departure | passes — exercises the helper directly |
| is a gradient, not a blanket lift | passes — same |
| scales with Complexity | passes — tests `macro.cpp`, not the wiring |
| **render: ghosts favour the approach** | **fails** |
