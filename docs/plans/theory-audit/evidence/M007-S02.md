| Rule | Case | What it settles |

**Rule 4 is checked in half, and the case says so.** "Continuous but dynamically
contoured" has two claims: continuity, which the hit count settles, and an
accent pattern forming an independent voice, which no cell reports. The
predicate checks the first and its comment records that it does not check the
second — a half-checked rule that admits it is honest; one that implies full
coverage is not.

**A registration-order bug was caught before commit.** The first version
appended `CHECKLIST.push(...)` at the end of the file, after the loop that
registers a test per rule had already run. All five cases were silently
never registered — the suite went from 26 tests to 26 and passed. Moving the
block above the loop registered them. A rule that is not registered is
indistinguishable from a rule that passes, which is precisely the failure mode
this milestone exists to remove, and it nearly shipped inside the fix for it.

All five proved to bite, each restored by inverse edit: clave mutation 0%→12%,

snare mutation 0%→9%, ghost roll 11→3 hits.

**A sixth predicate was written, failed, and was deleted rather than weakened.**
`ebb-layers-own-slots` read Rule 2 — "layers own slots" — as onset disjointness,
and reported the hat striking pulse 12, one of the backbeat snare's two slots.

The patch is not wrong. Rule 2's text forbids *"a layer that wanders between
territories"*, and a sixteenth hat stream crossing the backbeat has not left its
territory — coincidence is not wandering. More decisively, a static patch
assigns each lane one position set and **cannot** wander, so the rule describes
behaviour over time exactly as `theory-sub-saharan-africa` Rule 2 does.

So the verdict flips to not-checkable with that reason, and the predicate is
removed. The plan's instruction was not to weaken a predicate to make a patch
pass; the corollary it did not state is that a predicate can be wrong about what
its rule *says*, and the remedy is then to re-examine the triage rather than to
tune the threshold until the patch fits.
