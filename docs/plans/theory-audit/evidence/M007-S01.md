estimate came from reading rule headlines; the triage read the rule bodies, and
several headlines that sound like judgements turn out to name a value the table
holds — `theory-balkan` Rule 7's "tight ensemble, minimal humanize" ends

because the lead misleads in both directions: `theory-funk-soul` Rule 1, "The

`theory-electronic-breakbeat` Rule 5, "Arrangement is density automation",

that separately from the presence of a verdict. "Prose judgement" was
deliberately not used anywhere: the reasons name what judgement is needed and
why no cell reports it — "asks whether a part is playable and idiomatic for a
human player", "a measured non-isochronous subdivision profile, which the lane
table does not encode".

red that is a harness error is not the red a test-first step is looking for.

## M007/S01 — correction: two not-checkable verdicts were wrong

- `format` → exit 0
- `site-unit` → exit 0, 271 tests, 0 failures
- `doc-conformance` → exit 0
- 2026-09-12

Found after M007 merged, while gathering evidence for a successor programme.

`theory-funk-soul` Rule 6 — "the pocket is a fixed displacement field: kick a
few ms behind, snare at or slightly ahead, hat on top" — was excused as naming a
micro-offset field "which the lane table does not report". **The table has a
`Timing` column**, and the patch demonstrates the rule exactly: kick `+3ms`,
snare `−2ms`, hat `0ms`.

`theory-jazz` Rule 6 — "swing ratio follows tempo; voices' ratios differ
slightly" — was excused as "the table holds one swing value". It holds one *per
lane*: ride 0.45, hat 0.40, snare 0.35. The tempo half genuinely is not
checkable; the voices half plainly is, and the case says which half it checks.

**Why neither was caught.** M007/S02 audited the triage against the patch tables
and flipped six verdicts — but only over rules marked **checkable**, asking
whether a needed column was missing. The reverse audit, over rules marked
**not** checkable, asking whether a column claimed absent is actually absent,
was never run. And a false not-checkable verdict is invisible: there is no case
to register, so the registration guard cannot see it, and nothing fails.

The new case closes that. Verdicts excusing themselves by naming an absent
column now carry `absentColumn`, and the case asserts the column really is
missing from that page's table. Five verdicts carry it — Humanize on balkan,
Swing on breakbeat, Note on gamelan and sub-saharan, Timing on brazilian — and
changing brazilian's claim to `Swing`, a column it does have, fails with
`theory-brazilian.mdx rule 6 is excused because there is no Swing column, but
the table has one`.

Final triage: **92 rules, 49 checkable, 43 not.** M007's report and changelog
entry say 47 and 45; those numbers were right when written and are now wrong by
two, which is what B18 records.

Both new predicates proved to bite: the kick moved to `−3ms` fails
`fs-pocket-offsets`, and flattening every jazz lane to 0.40 fails
`jazz-voices-swing-differ`.
