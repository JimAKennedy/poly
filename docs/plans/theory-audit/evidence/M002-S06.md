The rule ships with **10 live suppressions across 9 files**, covering 8
references: `ref-3`, `ref-13`, `ref-20`, `ref-32`, `ref-33`, `ref-36` (twice),
`ref-38`, `ref-42` (twice). Each marker's reason was written from the claim it
sits on and names the M006 row that owns the upgrade.

**The plan's count check caught a real defect in the first attempt.** The
markers were written as multi-line MDX comments, and the hatch reads only the
line immediately above a citation — which for a multi-line comment is its
closing line, not the one carrying the token. The check reported `0 live
suppression(s)` while ten markers sat in the tree, and step 4's instruction —
that the count must equal the markers added — is what surfaced it. The markers
were rewritten as single long lines, matching the existing precedent at
`appendix-euclidean-reference.mdx:22`. The design's one-line-above rule was
kept; the markers were wrong, not the check.

Reverting that first attempt used `git checkout --` on the nine `.mdx` files
only, after confirming with `git status` that their sole uncommitted change was
the marker insertions and that `citation-tier.test.mjs` — which held this task's
new case — was not among them.

Both properties the plan asks to be proved, were:

- **The hatch is narrow.** Moving `13-drum-and-bass.mdx`'s marker two lines
  above its citation drops the suppression count to 9 and reports the citation
  again. A hatch that worked from anywhere in the file would not have noticed.
- **The rule reads the tier, not a hard-coded list of bad refs.** Flipping
  `ref-1` — Toussaint, cited approvingly throughout — from `A` to `B` makes 18
  previously passing citations fail. Both mutations reverted with inverse edits.

`ref-36`'s reason records what task 1 established by reading the page: the
source is Thomas Brett's commentary quoting Linn from an *Attack Magazine*
interview, so the interview is the upgrade target rather than the blog.

`ref-42`'s two markers state plainly that no M006 row owns them yet — M006/S01
carries B01–B07 for seven sources and this is the eighth. The marker says so
rather than naming a row that does not exist.
