F53 said the treatment was "thin", which is not a scope. Planning fixed one: the
section names the baque virado ensemble's parts and cites Crook (2009), whose
Afro-Brazilian traditions chapter covers maracatu directly.

The section already mentioned alfaias in passing — "alfaia bass drums drive a
relentless pulse" — so only four of the five parts were missing. The case
reported exactly that: `does not name caixa, mineiro, agbê, gonguê`.

**The addition stops where the sources do.** The parts and their roles are what
verification established: alfaias as rope-tuned bass drums carrying the weight,
the caixa opening with a *chamada*, the gonguê holding the timeline, the mineiro
and agbê as the shaken parts. A per-part account of each pattern is not
something any source consulted here supports, and the section does not attempt
one. The closing sentence says what the naming buys a Poly user — voicing rather
than only thickening — which is a claim about using the tool, not about the
tradition.

Both arms proved to bite, each restored by inverse edit:

- one part removed → `does not name gonguê`
- the citation removed → `fr-crook-2009 is not cited near "Maracatu: Weight and
  Repetition"`

The parts are asserted as a set, so dropping any one fails by name rather than
leaving the section quietly thinner than the row asks.
