**Seen red first.** The new tree test `ci.yml cancels superseded pull-request
runs and never a push to main` failed on the unmodified file:
`concurrencyShape` returned `null`. It passes with the block in place.

**What changed.** `ci.yml` declares `concurrency` with group

never cancelled. The group is ref-scoped, which is what the jk-standards check
requires of a non-global group.
