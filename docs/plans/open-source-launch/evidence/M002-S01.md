  contract` among them)

  `workflow-concurrency` → all pass, as before the change
- 2026-09-24

**Seen red first.** On the unmodified tree the guard's tree tests failed
three times: `ci.yml declares a top-level permissions block`,
`sanitizers.yml declares a top-level permissions block`, and `ci.yml's
top-level grant is exactly contents: read`. The other six workflows already
declared one. The fixture tests — a job-level-only block, a third-party
`repository:` with no SHA `ref:`, a tag ref, a missing `concurrency:` block —
fail by construction on every run, so the red proof is part of the gate
rather than a one-time observation.

**What changed.** `ci.yml` and `sanitizers.yml` gain `permissions:
contents: read` between `on:` and `jobs:`, each with a comment naming OS06.
`secrets-scan` keeps its job-local `pull-requests: write` and the sanitizer
`notify` job its `issues: write`; the guard asserts the former stays. The
repository's default workflow permission was already `read`, so no job's
token changed; the grant is now visible in the tree and held there.

**Wired three ways.** `scripts/check-guards.sh` runs the guard as
`workflow-hygiene contract`; `ci.yml`'s `code-quality` job runs it as a step;
`scripts/README.md` lists it, and `check-scripts-readme.sh` reports 39
entries all listed.

## M002/S01 — task 2: a superseded PR push cancels the run it replaces

- `node --test scripts/check-workflow-hygiene.mjs` → exit 0, 14 of 14
- `jk-standards workflow-concurrency` → pass, 3 groups, all ref-scoped or
  declared (was 2)
- `format` → exit 0
- `guards` → exit 0
- 2026-09-24

**Seen red first.** The new tree test `ci.yml cancels superseded pull-request
runs and never a push to main` failed on the unmodified file:
`concurrencyShape` returned `null`. It passes with the block in place.

**What changed.** `ci.yml` declares `concurrency` with group
`${{ github.workflow }}-${{ github.ref }}` and
`cancel-in-progress: ${{ github.event_name == 'pull_request' }}`, so a newer
push to a pull request cancels the run it supersedes and a push to `main` is
never cancelled. The group is ref-scoped, which is what the jk-standards check
requires of a non-global group.

OS07 closes.
