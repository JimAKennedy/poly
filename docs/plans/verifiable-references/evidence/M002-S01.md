Both cases passed the moment they were written, because task 1 generated the
manifest from the same anchors. That proves nothing, and the mutations are what
earn them. Three applied, tested and reverted, with both files confirmed
byte-identical afterwards:

| mutation | missing-anchor arm | orphan arm |
|---|---|---|
| a record is deleted from the manifest | **red** | green |
| an orphan record `ref-999` is added | green | **red** |
| a new anchor is added to the bibliography | **red** | green |

Each mutation trips exactly one arm, which is the property worth having: two
separate assertions rather than one over-broad check that fires on any
disagreement without saying which direction it ran.

The anchor set is read from the `.mdx` at test time. A literal 107 would agree
with a stale manifest for as long as nobody noticed, and the regex throws on
zero matches, so a changed anchor convention is a loud failure rather than a
check that quietly asserts nothing.
