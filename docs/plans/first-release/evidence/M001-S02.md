### Two things the earlier enumeration missed, and how they were found

**`tags is not defined`.** `const tags` was declared inside the cloth block, and
one line outside it still wrote lane names into `tags.children[li]`. It threw on
page load, which is why the first suite run **hung past 600 seconds** rather
than failing: with the page dead, every spec sat on its 30-second timeout.

Greps for removed *selectors* could not have caught it — the reference was to a
JS binding, not a DOM id. What found it was loading the page in Chromium and
reading `pageerror`: one error, `tags is not defined`. After the fix: **0 errors,
7 lane strips rendering.**

**Two more loom tests.** `accent-preview.spec.mjs` and `velocity-mute.spec.mjs`
each had a describe reading pixels off the `#loom` canvas through a local
`loomHitPixels` helper rather than through a selector the pattern matched. The
suite found them, not the enumeration. Both describes and both now-dead helpers
are removed.

**360 → 358.** The rule this task establishes for the rest of the milestone: for
a removal of this shape the suite is the authoritative enumeration, and a grep
over selectors is a starting point rather than a census. Three separate
enumerations in this slice were incomplete before the suite settled it.
