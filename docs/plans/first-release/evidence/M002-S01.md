### A guard from another programme had to change, and the owner decided how

`site/tests/idiom-break-framing.test.mjs` (theory-audit M071 S05) failed four
cases. It requires every knowing idiom-break to carry **both** a
`:::note[Bending the idiom]` aside **and** a link into that tradition's
`#what-breaks-the-idiom` section — exactly the links this task removes. The two
could not both stand, so the run halted rather than resolving it: the guard
belongs to another programme and its header states it exists so "a reintroduced
unframed idiom-break would silently pass the build".

The owner chose to drop the link from `present` and keep the aside. The guard's
subject survives — the aside is what makes a break visibly framed — and only the
half that depended on a published page went. The header now records why.

**Re-proved after weakening**, because a guard nobody re-proves after narrowing
it is worse than no guard: replacing the aside title in `03-afro-cuban`,
`14-synthesis` and `appendix-presets` turns S05-F4, S05-F5, S05-F2 and S05-F3
red respectively, each reverted.

One measurement error on the way: a first pass reported S05-F2 green under
mutation. The line-matcher had matched **S05-F21**, an unrelated case in
`07-balkan.mdx`, by substring. Re-run with exact matching, S05-F2 goes red like
the rest.

### A consequence worth recording

`S05-F2` and `S05-F3` now assert **identically** — same file, same single
`present` item. The deep-dive link was the only thing distinguishing the gamelan
break from the Balkan one, so the guard can no longer tell which of the two
`appendix-presets` asides is missing: removing either fails both cases. Their
`rule` strings still differ, so the intent is documented, but the assertion no
longer separates them. Recorded rather than fixed — restoring the distinction
means giving each aside a distinguishing string, which is prose this task was
not asked to write.
