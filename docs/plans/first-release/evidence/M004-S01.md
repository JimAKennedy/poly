## M004/S01 — task 1: the lane head keeps its name legible with the export handle, and FR26 closes

- `ledger` → exit 0, 5 ledgers conform
- 2026-09-22

**Found by task 2, fixed first.** The first capture taken with the mock's
`?export=1` seam — so the header shows Export as the plugin always does —
rendered the BELL lane's name as a sliver. Measured in the DOM, same page,
1280px viewport:

| | head | name column | name box | head buttons |
|---|---|---|---|---|
| mock default | 40px | 104px wide | 18px tall at head top + 3 | 2 |
| with the export handle | 40px | 76px wide | **11px tall**, at head top | 3 |

The third button narrows the column, "Anchor pulse" wraps to two lines, and
because the name was a shrinkable flex item inside a fixed-height column with
`overflow: hidden`, the name — not the role — absorbed the overflow. Wider
viewports (1440, 1600) did not change it: the role wraps at any width once the
column loses 28px.

**The fix makes the worst case deterministic.** `.strip .nm` gets
`line-height: 12px`, `.strip .nm b` gets `line-height: 16px` and
`flex: none`, and the head is 42px = 16 + 2 margin + 2×12. The old 40px was
"sized for the worst case" against the browser's default line heights, which
is how it was already one pixel short before the handle made it seven.

**The guard was vacuous once, and was seen red before being trusted.**
`webui/tests/lane-head.spec.mjs` checks every lane with and without the
handle. Its first draft asserted the name's box lay inside the head and the
column did not overflow — and passed on the broken CSS, because a shrunken
flex item hides its overflow inside itself. It now also asserts the name
element's own `scrollHeight` does not exceed its `clientHeight`:

| CSS | mock default | with the handle |
|---|---|---|
| original | pass | **red — `Bell: 7px of text hidden`** |
| fixed | pass | pass |

The seam case asserts three head buttons are present, so it cannot go green by
the handle failing to mount. FR26 closes; the ledger's row, DoD line and
`webui-e2e` token, the plan's amendment and the decisions entry land with it.
